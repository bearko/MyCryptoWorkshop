# 島づくり（試作）

工房とは別のページ（`island.html`）で遊ぶ、島の町づくりシミュレーションの試作です。PixelLab で生成した建物の絵を、斜め上から見た地図に並べて島を育てます。工房のセーブとは別に、このブラウザに保存されます（`mycryptoisland.save.v1`）。

> いまの `?test=2` はフェーズ 1「新天地で実績を上げろ」（[ISLAND_PHASE1.md](ISLAND_PHASE1.md)）を開きます。この自由建築モードはテスト用に `island.html?test=2&mode=free` で開けます（フェーズ 1 のメニュー「テスト」からも行けます）。

## 開き方

- `https://workshop.bearko.games/?test=2` で直接開く（工房の読み込みより先に `island.html?test=2` へ移る）
- `?test=2` のときは右上に「テスト」が出る：資金 +50,000・工事をすべて終える・1 か月進める・すべての建物を解放

## 遊び方

1. 下の帯から建物を選び、地図のマスを選んで建てる（マウスはクリックで建つ。指は 1 回目で場所を選び、同じマスをもう一度押すか「建てる」）
2. 工事は日数がかかる。更地に足場が 1 段ずつ組み上がり、完成すると敷地の縁からキラキラが吹き上がる
3. 月末に、売上・税・維持費が資金に入り、満足度に応じて人が引っ越してくる（不満が強いと出ていく）
4. 人口が増えると、建てられる建物が増える。目標は人口 1,000 人・支持率 70%

操作：ドラッグで移動、ホイール（指 2 本）で拡大縮小、R で向きを変える、Esc でやめる、Space で一時停止。

## 地図と絵の規格

| 項目 | 規格 |
| --- | --- |
| 1 マス | 敷地の上面が横 200 × 縦 110 のひし形。縁の歩道の厚み 6 |
| 並べ方 | 右下のマスへは横 +100・縦 +55、左下へは横 −100・縦 +55。奥から手前の順に描く |
| 基準点 | 敷地の上面のいちばん手前の角。どの絵も「下端から 31 上、手前のマスの横の真ん中（x = 100）」 |
| 絵の大きさ | 1 マス 200×200、1 マス高層 200×280、2 マス 300×255、2 マス高層 300×340 |
| 向き | `rd`（入口が右下）と `lu`（背面）の 2 枚。左下（`ld`）と右上（`ru`）は左右反転で描く |
| 2 マス | 入口が右下・左上なら j の向き、左下・右上なら i の向きに延びる。反転した絵では手前のマスが右（x = 200） |
| 光 | 右上から。反転した 2 方向は光が逆になるが、試作ではそのままにする |

絵は `public/island/b/<建物の id>/rd.png・lu.png`。地面は `public/island/tiles/`、工事の足場とキラキラは `public/island/fx/`（足場は 1 マスごとに 3〜5 段。2 マスの建物は両方のマスに組む）。

## 暮らしとお金（`src/island/sim.ts`）

- 1 日 0.6 秒（⏩ で 4 倍）。30 日で 1 か月
- 働ける人は人口の 6 割。働き口より少なければ、店や会社は人手の割合でしか回らない
- 必要（食事・買い物・信仰・娯楽・治安・医療・教育）は、人口が一定を超えると求められる。満たされ具合は「建物が満たせる人数 ÷ 人口」
- 満足度 ＝ 必要の満たされ具合の重みつき合計 ＋ 仕事の足り具合 × 0.18 ＋ 魅力（最大 0.08）
- 月末：売上（店は客の取り合い、会社は人手と後押し、観光は島の魅力で決まる）＋ 税（働く人 12・住む人 3）− 維持費
- 支持率は満足度と後押しへ少しずつ寄る。満足度 0.4 以上で空き家の 25〜85% が埋まり、0.3 未満で 5% が出ていく

建物の数値は `src/island/defs.ts`。試作の当たりで、遊びながら直す。

## 絵の作り方

`scripts/island/generate.py`（PixelLab の API。`PIXELLAB_API_KEY` が要る）と `scripts/island/fx.py`（地面・足場・キラキラ）。土台は `scripts/island/bases/`、建物ごとの文は `scripts/island/buildings.json`。

1. 空き地の土台（または住宅の土台）を PixelLab の Edit image（`/v2/edit-images-v2`）に渡し、「On this empty lot, build …」で正面を作る
2. できた正面を同じ API に渡し、「Show the back side of the same building …」で背面を作る
3. 敷地の縁が規格とずれていれば、平行移動で合わせる（縁の形そのものが崩れていれば作り直す）
4. 左右反転はゲームが描くときに行う

プロンプトの一覧は、ドキュメント「建物アセットの規格と生成プロンプト」にまとめてある。
