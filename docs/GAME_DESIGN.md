# My Crypto Workshop — ゲームデザインドキュメント

> My Crypto Heroes（マイクリ）の世界で、エクステンション（装備品）を作って売るクラフト工房インクリメンタルゲーム。
> モデルケース: [Bookstore Incremental](https://store.steampowered.com/app/4664470/Bookstore_Incremental/)

## 1. コンセプト

| 項目 | 内容 |
| --- | --- |
| ジャンル | アクティブ寄りのインクリメンタル（放置要素あり）/ お店経営 |
| 舞台 | マイクリ世界の「クラフト工房」。奥が工房、手前が店頭 |
| プレイヤーの役割 | 工房の店主。エクステンションをクラフトして陳列し、来店したヒーローに売る |

### Bookstore Incremental から取り入れる骨格

| Bookstore Incremental | My Crypto Workshop |
| --- | --- |

## 2. コアループ

```
┌───────────── 営業日（数十秒〜数分） ─────────────┐
│ 工房: 魔法の壺がクラフト（クリックで加速）       │
│   ↓ 完成品                                       │
│ 店頭: 陳列棚に並ぶ → ヒーローが来店して手に取る   │
│   ↓                                              │
│ レジ: 行列 → 会計 → GUM 獲得                     │
│ 妨害: 泥棒・工房荒らしをクリックで撃退           │
└──────────────────────────────────────────────────┘
            ↓ 閉店（営業成績）
      スキルツリーで GUM を使って強化
            ↓
        翌営業日へ（より速く・より高く売れる）
```

- **営業日制**: 1日は短い営業時間で区切り、閉店後にスキルツリーでまとめて強化する。
  1プレイが短く「もう1日だけ」を繰り返せる。営業時間そのものも強化対象にする。
- **ボトルネックの移動**: 生産が足りない → 棚が空く → 客が帰る。
  棚が足りない → クラフトが止まる。レジが遅い → 行列で客が怒って帰る。
  どこか1つを伸ばすと別の場所が詰まる、という状態を常に作る。
- **アクティブ操作**: 壺・レジ・泥棒・エネミーをクリックすると得をする。
  スタッフを雇うと自動化されていく（アクティブ → 放置への移行）。

## 4. MVP（今回実装する範囲）

「1日営業 → 強化 → 翌日」が気持ちよく回ることを確認するための最小構成。

### 4.1 画面

- **工房シーン**（上）: 工房背景＋購入済み設備のオーバーレイ。魔法の壺のクラフト進捗、工房荒らしのエネミー。
- **店頭シーン**（下）: 陳列棚、レジ（クリスくん）、入口。ヒーローが歩いて買い物し、泥棒が盗んで逃げる。
- **HUD**: 所持GUM、営業日、残り時間、本日の売上。
- **閉店リザルト**: 売上・販売数・来客数・帰った客・盗難・捕獲・新規図鑑登録。
- **スキルツリー**: ドラッグで移動できるノードグラフ。
- **図鑑**: 解放済みシリーズのエクステンション一覧（作ったことがあるものだけ表示）。

### 4.2 システム

| システム | MVP仕様 |
| --- | --- |
| クラフト | 壺が一定時間ごとにエクステンションを1個完成。解放済みシリーズ×レアリティからランダム。壺クリックで進捗加速 |
| 在庫 | 完成品は陳列棚へ。棚が満杯ならクラフト停止（搬送レーン解放で倉庫にストック） |
| レアリティ | Common → Uncommon → Rare → Epic → Legendary をスキルで解放。高レアほど高価で出にくい |
| 客 | ヒーローが来店 → 棚から1つ取る → レジに並ぶ → 会計。棚が空だと待って、待ちきれないと帰る |
| 客層 | Common ヒーローから始まり、スキルで高レアヒーローが来店。高レアの客ほどチップが多く、高い品を選ぶ |
| レジ | クリスくんが自動会計。レジクリックで会計を早められる。行列で待ちすぎた客は商品を戻して帰る |
| 泥棒 | 2日目以降、ヴィランヒーローが来店して商品を盗み逃げる。クリックで捕獲 → 懸賞金＋商品を取り返す |
| 工房荒らし | 3日目以降、エネミーが壺に取りつきクラフト速度半減。クリックで退治 |
| 図鑑 | 初めて作ったエクステンションを登録。登録数に応じて販売価格ボーナス |
| スキルツリー | 約45ノード。五勢力の枝（下表） |
| セーブ | localStorage に自動保存 |
| サウンド | BGM と SE。ミュート切替 |

### 4.3 スキルツリーの枝（五勢力）

| 勢力 | 担当 | 主なノード |
| --- | --- | --- |
| 朱雀（上） | クラフト | 壺の火力、職人の手際、同時クラフト、鍛冶ハンマー、各レアリティ製法、鑑定眼、マインちゃん雇用 |
| 青龍（右） | 集客 | 呼び込み、ランタン装飾、居心地、案内板、団体客、各客層の解放 |
| 黄竜（下） | 経営・レジ | 値付け上手、クリスくん研修、レジ打ち、おもてなし、営業時間延長、図鑑ボーナス |
| 白虎（左下） | 防犯 | 懸賞金、足止め罠、防犯ベル、マイクリくん警備、虫除け結界 |
| 玄武（左） | 陳列・レシピ | 陳列棚増設、搬送レーン、倉庫拡張、各シリーズのレシピ（マスケット、ペン、カタナ…） |

ノードはデータ駆動（`src/game/skills.ts`）で、定義を足せばツリーが広がる構造にしておく。

## 5. 拡張要素（MVP 以降に積み上げる候補）

Bookstore Incremental の「アップグレードが膨大にある」体験に向けて、マイクリらしさで量を出す。

### 5.1 商品・クラフト
- **全シリーズ解放**: 178シリーズ・約950種のオリジナルエクステンション。モダン（Modern）拡張も追加。
- **真・シリーズ**: `55xx` の「真・MCHブレード」等を最上位の超レア枠に。
- **魔石素材**: イフリート / リヴァイアサン / ティアマト / ガルーダの魔石（`Image/Materials/Gemstones`）を消費してクラフト。属性でできやすいシリーズが変わる。
- **クラフト工程の多段化**: 壺（素材投入）→ 搬送レーン → 具現化カプセル（完成）の3工程をそれぞれ強化。
- **エクステンションのレベル上げ**: 同じ品を重ねてLvを上げ、単価アップ（原作の合成・Lv要素）。
- **ステータス鑑定**: HP/PHY/INT/AGI（`max_level_stats`）の高い個体ほど高値。鑑定SE（`insp.mp3`）。

### 5.2 客・ヒーロー
- **注文システム**: ヒーローが「ゆかりの品」を名指しで注文（例: 織田信長 → へし切長谷部、ナポレオン → グランダルメ）。応えるとボーナス。
- **常連客・好感度**: 来店回数で好感度が上がり、そのヒーローのパッシブスキル名を冠したお店バフを得る。
- **ヒーロー図鑑**: 来店したヒーローを登録。勢力・属性（Attribute）ごとのコンプリート報酬。
- **勢力デー**: 朱雀の日は朱雀ヒーローが多く来店、など。
- **レプリカヒーロー**: 後半の客層として `replica` カテゴリを追加。
- **英雄の酒場（実装済み）**: スキルツリーの「英雄」でヒーローをスカウトする（酒場・広間・伝説の間の 3 段、計 38 人、各 Lv 1〜5）。ストロベリー以降のシリーズのレシピは、ゆかりのヒーローをスカウトすると教えてもらえる（レシピを 1 つずつ買う作業の代わり）。開店前に最大 5 人をパーティに編成すると工房のバルコニーに立ち、スキルが溜まるたびに発動する（初回はカットイン）。同じ属性 2 人以上でスキルが早く溜まり、同じ陣営 3 人以上でスキルの効果 +20%。同じ種類のバフは重ねるほど効きが半減するので、色々な役割を組み合わせるのが強い。レジェンダリー解放後からクリアまでの GUM の使い道（スカウトと Lv 上げ）にもなる。スカウトしたヒーローはパーティ外でも「サポート効果」を常に発揮する（スキルの種類ごと: 売上→販売価格、集客→来客ペース、生産→クラフト時間、目利き→最高レア、退治→泥棒の逃げ足・懸賞金、会計→会計時間、足止め→待ち時間、来店→ランドオーナーの支払い、お目当て→コレクター・注文の支払い、補充→補充間隔、研究→研究ポイント。Lv と段（酒場・広間・伝説）で強くなり、どのヒーローも Lv 1 ごとに販売価格 +0.5%）。

### 5.3 妨害・イベント
- **泥棒の多様化**: 足が速い / 複数盗む / 変装して普通の客に紛れる など、ヴィランごとに個性。
- **レイド**: 黒髭海賊団など、泥棒の集団襲撃イベント（`raid.mp3`）。
- **工房荒らしの種類**: エネミーごとに「棚を倒す」「レジを止める」など別の妨害。
- **金宝箱**: Legendary 完成時に金宝箱演出（素材リポジトリの `Data/Effects/GoldChest` の紙吹雪）。
- **カットイン**: 高レア完成・大口客で `Style/Cutins` のカットイン演出。

### 5.4 経営・メタ進行
- **スタッフ育成**: クリスくん / マインちゃん / マイクリくんにスキルツリー、ヒーローをスタッフとして雇用。
- **プレステージ（ランド移転）**: 店をたたんで別のランドへ移転し、クリプタイドの加護（`Image/Cryptids`）で永続ボーナス。Cp をプレステージ通貨に。
- **帰る客を 0 に近づける（実装済み）**: コレクター客の探し物は 40%（品揃えの評判で最大 100%）が店の在庫のシリーズ、それ以外も工房で作れるシリーズから選ぶ。特注受付で待っている客の品を次のクラフトで作って手渡し、代わりの品のご提案で待ちくたびれた客も別の品を買う。店舗拡張で店に入れる客は 24 → 48 人、繁盛店で来客ペース最大 +100%、安心の店内でエネミー・泥で帰る確率を最大 -96%。自動プレイの Day 95 では 1 日約 1,150 人が来店し、帰る客は 0.2% 前後。
- **称号（実装済み・エンドコンテンツ）**: 9 ランド × 6 段階（コマンダー 1兆 / ナイトコマンダー 3兆 / ナイト 10兆 / G5 30兆 / マエストロ 60兆 / キング 150兆 GUM）。そのランドに移転した周回でクリアした後に獲得でき、移転しても残る。効果はそのランドのクリプタイドの強化: 加護を 0.5〜1.5 回分上乗せし、ランドの日に来るクリプタイドがいる間 20 秒、売上 +25%（称号 1 つごと）。ランキングには最高の称号を名前の横に表示。3 つのランドで G5 以上を取ると **MCH Verse Pass**（200兆 GUM・研究 3 万・ダスト 2,000・エンブレム 100、販売価格 +100%・Cp +50%・クリプタイドの売上ボーナス 2 倍、ランキングの称号が MCH Verse Pass になる）。自動プレイでは、3 周目以降の周回の開始からおよそ 30 分でコマンダー、100 分で G5、200 分でマエストロ、430〜460 分でキング（そのランドに留まり続けた場合）。
- **出張販売**: バトル背景（`Image/Backgrounds`）の各地へ出店。場所ごとに客層と相場が違う。
- **相場変動**: シリーズごとの人気が日によって変わる。
- **実績・デイリー依頼**: エンブレム / ゴールドダストを報酬に。
- **設備の見た目**: 工房背景のレイヤーをさらに増やし、強化するほど工房がにぎやかになる。

### 5.5 プラットフォーム

## 7. 技術構成

- **Vite + TypeScript**（フレームワークなし）。シーンは Canvas 2D、UI は DOM。
- ドット絵は `imageSmoothingEnabled = false` / `image-rendering: pixelated` で拡大。
- ゲームロジック（`src/game/`）は描画から分離し、Vitest でテスト可能にする。
- 素材は `scripts/sync-assets.mjs` で `public/mch/` にコピーし、`src/generated/catalog.json` を生成。
