# 経営モードのデザイン方針

経営モードで最も重視するのはデザインです。部品を並べた管理画面ではなく、「町で店を営み、会社を育てている」手触りを、MCH の素材とコードで描いたドット絵で出します。

- 色・文字・余白・部品の決まり：`design/keieimode/`（デザインシステム「経営モード」）。CSS 変数は `src/ui/empire/tokens.css`（`npm run design:tokens` で作る）
- ドット絵の描き方と自動検査：`docs/pixel-rules.md`
- 画面の見本：Claude Design のキャンバス「経営モード 画面デザイン」（PC 1280×720 とスマホ 390×844）

## 1. UI を世界の中の物として描く

画面の情報は、なるべく町の中にある物の姿で見せる。

| 情報 | 見せ方 |
| --- | --- |
| 月次決算 | お品書き（帳簿）。紙の行に売上と費用、下に利益 |
| 施策 | 稟議書に判子を押す。押した瞬間に紙が揺れる |
| ステークホルダーの要望 | 絵馬。期限が近いと文字が赤くなる |
| ライバルの動き・事件・時代の変化 | かわら版。見出しと MCH のヒーローの絵 |
| 店の情報 | 区画に置いたエクステンションの絵と、持ち主の色の縁 |
| 株主総会 | 壇上の演説原稿を組み立てる |
| 助言 | マインちゃんが吹き出しで話す |

町が生きている感じは動きで出す：配送トラック、行き交う客、売上の硬貨が店の上で跳ねる。町は常に昼で描き、昼夜の切り替えはしない。配色は「市」（濃い藍と木の色に、提灯の黄と自社の青緑）。

## 2. 縮尺：世界・国・エリア

会社が大きくなるたびに、カメラが一段引いて世界が広がる。全世界は 9 つのランド（国）、ランドはランドセクタ（エリア）でできている。エリアのレアリティがそのまま広さになる。

| フェーズ | 縮尺 | 地図 |
| --- | --- | --- |
| 1 店主 | 店内 | 創業の町（Common）を 2 倍にして、自社の店を中心に置く |
| 2 エリアチェーン | 町 | Common のエリア（10×8 マス。外周 1 マスは木、内側 8×6 が区画） |
| 3 全国 | 国 | ランドの背景の上に、11 のエリアを浮いた板として並べる。板の大きさがレアリティ |
| 4 世界 | 世界 | 9 つのランドを島として並べた海図 |
| 5 グループ | 会議卓 | 業態カードと、9 つの Legendary エリアの番付 |

| レアリティ | 広さ（マス） | 1 ランドあたり |
| --- | --- | --- |
| Common | 10×8 | 4 |
| Uncommon | 14×11 | 3 |
| Rare | 17×14 | 2 |
| Epic | 20×17 | 1 |
| Legendary | 23×20 | 1 |

最後は、9 つの Legendary エリアで売上・ブランド・影響の 3 冠を争う（27 マス）。

## 3. 操作の快適さ

- 常に見えるのは最小限：屋号、資金、日付、フェーズ、そのフェーズの 1 つの目標。詳しい情報は開いたときだけ出す
- 押すべきボタンは 1 つだけ光らせる（「月を進める」）。ほかの指示は下の列にまとめる
- よく使う操作と、その対象は 1 か所に集める（区画を選ぶと、その横に詳細と出店ボタンが出る）
- 区画にマウスを乗せると、名前と大事な数字を小さな札で出す（押さなくても分かる）
- 文字で書かなくても分かるものは、色・形・アイコンで示す（持ち主は縁の色、期限は赤い文字、予定は点線の枠）
- 判断に要る数字（費用・効果の見込み）は、そのボタンの上か横に必ず出す
- 時代やフェーズごとに機能を段階的に開き、最初から全部を見せない

### 画面幅ごとの組み方

| 幅 | 組み方 |
| --- | --- |
| 1024px 以上 | 3 列の机：左にお品書き、中央に地図、右に絵馬とかわら版。下に指示ボタンの列と「月を進める」 |
| 600〜1023px | 2 列：左に地図、右にお品書き・絵馬・かわら版を縦に積む |
| 599px 以下（スマホ） | 地図が上、折りたたみの行が下、一番下にドック。詳しい情報は下から出るシートで開く |

スマホの規則：

1. 常に見えるのは 4 つだけ：1 行のヘッダー（屋号・資金）、地図、折りたたみの行、ドック（指示・月を進める）
2. 地図は原寸（1x）で画面の上半分以上に出し、指でずらして見る
3. かわら版は地図の下端に 1 行で流し、押すと記事が開く
4. 折りたたみの行は閉じたままでも、一番大事な数字を 1 つ出す
5. 詳しい情報は下から出るシートで開く。区画を押すとシートが開き、選んだ区画が見える位置に地図がずれる
6. タップの的は 44px 以上。文字は本文 14px、補足 12px を下限にし、小さくして収めずに折りたたむ
7. スクロールしないと「月を進める」が押せない作りにしない

## 4. 素材

- 画像は MCH の素材が基本：ヒーロー、エクステンション、ランドセクタ、ランドの背景、キャラクター、BGM・SE
- 区画の設備はエクステンションの絵を原寸（64×64）で置く。段階（Lv1〜5）はレアリティ（Common〜Legendary）。住宅はドールハウス
- 道路・地形・駅・物流センター・船・島のように、エクステンションにないものだけをスクリプトで生成する（`scripts/pixel/`）
- ランドの背景（`Image/Backgrounds/2105〜2905`）はドット絵に変換して、国の画面の背景とランドの札に使う。エリアの地図そのものには使わない
- 色数の少ないシリーズ（ラーメン、お寿司、いちごケーキ）を優先する
- 拡大は整数倍だけ。画像には `image-rendering: pixelated`

MCH の素材を実測した結果（2026 年 10 月）：

| 素材 | サイズ | 1 枚の色数 | 輪郭 |
| --- | --- | --- | --- |
| ヒーロー・エネミー | 64×64 | 約 1,000〜2,400 | 黒い外郭線あり・なしが混在 |
| エクステンション | 64×64 | 16〜1,500 程度 | 多くは外郭線なし |
| ランドセクタ | 64×64（背景付き） | 約 50〜170 | 背景はランドカラー |
| マインちゃん | 72×140 | 約 30 | ほぼ黒（#181818）の外郭線 |

自作する建物は、マインちゃんの描き方に合わせる：ほぼ黒の外郭線、1 枚 32 色以内、共通パレット。

## 6. 確認

- 画面を変えたら `?test=1` で開き、1280×720・1920×1080・390×844 で撮影する（`node scripts/shots.mjs`）
- 撮影を、この方針と `docs/pixel-rules.md` に照らして自己レビューしてから PR にする
- 生成した絵は `npm run pixel:lint` で検査する
