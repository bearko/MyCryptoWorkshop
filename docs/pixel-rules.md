# ドット絵のルール（経営モード）

スクリプトで生成する絵（地形・道・駅・物流センター・船・島・ランドの背景）と、画面での見せ方の決まりです。ドット絵の解説書『Pixel Logic』（日本語版）の該当章を、生成と検査に使える形に要約しました。解説書の文章や図はリポジトリに入れません。

各ルールの右の ID は `npm run pixel:lint`（`scripts/pixel-lint.mjs`）の検査の名前です。`—` は人が見て確かめるもの。

## 生成の工程

すべての絵を、この順で作る（`scripts/pixel/`）。

1. 形：パレットの番号で面を塗る
2. ほぼ黒の外郭線（`#181818`）：前面の物だけ。背景には付けない
3. 陰影：光源は左上。明るい面は左と上、暗い面は右と下
4. 内側だけのアンチエイリアス（AA）
5. 孤立ドットとバンディングを消す

## ルール

### 大きさ

| ルール | ID |
| --- | --- |
| 1 つの画面に、ドットの大きさが違う絵や、回転させたドットを混ぜない | `scale` |
| 拡大縮小は整数倍だけ。画像とキャンバスには `image-rendering: pixelated` | `scale` |
| 地図の 1 マスは 64px。MCH の 64×64 素材を原寸で置く | — |

`scale` は撮影のとき（`scripts/shots.mjs`）に、経営画面のすべての `img` と `canvas` について「表示の大きさ ÷ 元の大きさ」が整数かを確かめる。

### 色

| ルール | ID |
| --- | --- |
| 生成する絵は共通パレット（`scripts/pixel/palette.mjs`）の色だけを使う | `palette` |
| 1 枚 32 色以内（ランドの背景は 24 色以内） | `colors` |
| 明暗の段階（ランプ）ごとに色相をずらす。影は青や紫の方向へ、茶色や肌色の影は赤みへ | — |
| 半透明のドットを使わない（不透明か、完全に透明か） | `alpha` |

### 線と輪郭

| ルール | ID |
| --- | --- |
| 前面の物（建物・車・船・人）は、外周を途切れないほぼ黒の線で囲む | `outline` |
| 外周（透明に接するドット）に AA の中間色を置かない | `outline` |
| 段差の長さは単調に増やすか減らす。長い段差の間に短い段差を挟まない（4-1-4 など） | `jaggy` |
| 45 度は 1-1-1 の段差で描く | `jaggy` |
| 背景（地形・海・遠景）には輪郭線を付けず、彩度とコントラストを抑える | `bg-contrast` |

### ノイズ

| ルール | ID |
| --- | --- |
| まわり 8 マスがすべて違う色の 1 ドット（孤立ドット）を残さない | `orphan` |
| 2 列のドットが同じ長さで寄り添って並ぶ（バンディング）を避ける | `banding` |
| 輪郭に沿ってぼかすだけの陰影を使わない | `banding` |

### ディザリング

| ルール | ID |
| --- | --- |
| ディザは、低コントラストの 2 色で広い面（草地・海・砂浜）を埋めるときだけ | `dither` |
| コントラストの高い 2 色を格子状に混ぜない | `dither` |
| タイルのつなぎ目でドットがつながらない（2 枚を並べて検査する） | `seam` |

## 検査のしきい値

| ID | 失敗とする条件 |
| --- | --- |
| `palette` | パレットにない色が 1 つでもある |
| `colors` | 色数が上限を超える |
| `alpha` | 0 と 255 以外のアルファがある |
| `outline` | 前面の絵で、外周のドットのうち外郭線の色でないものが 2% を超える |
| `orphan` | 孤立ドットが、不透明なドットの 1% を超える |
| `banding` | 同じ長さ（3 ドット以上）で上下に並ぶ別の色の帯が 4 組を超える |
| `jaggy` | 外形の段差に「長・短・長」（差が 2 以上）が 3 か所を超える |
| `dither` | 隣り合うドットが市松に並び、明るさの差が 25%（輝度）を超える |
| `bg-contrast` | 背景の絵で、明るさの幅（上位 5% と下位 5% の差）が 45% を超える |
| `seam` | タイルを 2×2 に並べたとき、つなぎ目に孤立ドットやバンディングが新しく出る |

検査は `public/empire/` に作られた絵すべてに走り、CI でも回る。絵ごとの種類（前面・背景・タイル）は `scripts/pixel/manifest.mjs` に書く。
