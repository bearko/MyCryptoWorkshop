# LotTile

地図の区画。エクステンションの絵を原寸（64×64）で置き、舗装の縁の色で持ち主を示す部品です。

- 1区画 = `tile`（64px）。絵は拡大縮小せず、`image-rendering: pixelated`
- 縁は `border-band` 相当の2〜3ドット：自社 `ours-400`、ライバル `rival-400`、町の店 `neutral-400`
- 色だけに頼らないよう、自社とライバルの区画には小さな旗（形が違う）を角に付ける
- 段階はエクステンションのレアリティ：ラーメンならLv1カップラーメン → Lv2油そば → Lv3醤油ラーメン
- 選んだ区画は `lantern-400` の3px枠で囲む
- 実際の地図ではスクリプトが舗装と縁を描く。この部品は、その見え方の基準
