# Ledger

先月の決算を、店のお品書きのように見せる部品です。

- 地は `plum-600`、枠は `border-panel` の `night-800`。行は `paper-200` の紙、売上の行だけ `paper-100`
- 数字は `figure`（DotGothic16）、利益は `figure-lg` の `lantern-400`。前月比は `ours-200`（増）か `rival-200`（減）
- 行は「売上 → 原価 → 人件費 → 家賃 → 配送費・SV」の順。利益は最後に、暗い枠の中に1つだけ大きく出す
- スマホでは折りたたみの行（`FoldRow`）に「利益 1,480万 +6%」だけを出し、開くと `BottomSheet` の中にこの部品が入る
- 利用側が渡すもの：月、行の名前と金額、利益、前月比
