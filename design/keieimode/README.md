# 経営モード デザインシステム

Claude Design で作ったデザインシステム「経営モード」を取り込んだものです。色・文字・余白の値は `tokens.json` にあり、`npm run design:tokens` で `src/ui/empire/tokens.css` を作り直します（手で書き換えない）。部品ごとの決まりは `components/` にあります。

MyCryptoWorkshopの経営モード（1店舗から9ランドの財閥へ）の画面を作るためのデザインシステムです。昼の町を、夕暮れの市のような濃い藍と木の色の机から見下ろす、という見た目にそろえます。画像はMy Crypto Heroes（MCH）の素材を基本にし、UIは画面の中の「物」として描きます。

## 基本の考え方

- **主役は町の地図**。UIは地図を囲む机と道具。地図の上に浮かぶのは、選んだ区画の枠とマインちゃんの助言だけにする
- **UIは物として描く**。決算はお品書き（`Ledger`）、要望は絵馬（`EmaCard`）、ニュースはかわら版（`Kawaraban`）、施策は稟議の判子
- **設備はエクステンションの絵そのもの**。区画にMCHのエクステンションを原寸で置き、縁の色で持ち主を示す（`LotTile`）
- **押すべきボタンは1つだけ光る**。`lantern-400` は「月を進める」と選んだ区画の枠にだけ使う
- **町は常に昼**。昼夜の切り替えはしない。地図の色はドット絵の側で決め、UIの色を地図に重ねない

## 言葉づかい

- 町の商人の言葉で、短く書く。「〇〇してください」より「〇〇できます」「〇〇しませんか」
- 金額は「万」「億」で丸める：`1億1,840万`、`−7,810万`。マイナスは全角のマイナス記号（−）
- 期間は「あと2か月」「3年目　4月」。日付と数字の間は全角スペース
- 例：「物流センターから2マスの配送圏に店をまとめると、配送費が下がります。」

## 色

一つのテーマ（市）だけを持ちます。トークン名はCSS変数として `var(--plum-700)` のように使います。

| 役割 | トークン | 使い方 |
| --- | --- | --- |
| 地 | `night-900` | 画面の一番奥。地図の額縁 |
| 線とインク | `night-800` | すべての枠線（3px）、紙の上の文字 |
| 机 | `plum-700`、`plum-600` | ヘッダー、掲示板、お品書き、指示ボタン |
| 紙 | `paper-100`、`paper-200`、`ema-300` | 区画の詳細、かわら版、お品書きの行、絵馬 |
| 文字（暗い面） | `text-100`、`text-300` | 本文と補足 |
| 主ボタン | `lantern-400` | 「月を進める」、選んだ区画の枠 |
| 自社 | `ours-400`（図形）、`ours-200`（文字） | 区画の縁、指示ボタンの上帯、良い数字 |
| ライバル | `rival-400`（図形）、`rival-200`（文字） | ライバルの区画の縁、ライバルの数字 |
| 警告 | `alert-ink`、`alert-ink-deep` | 紙と絵馬の上の期限・警告 |

- 文字はすべて背景に対して4.5:1以上。`ours-400` と `rival-400` は図形専用で、小さな文字には使わない
- 自社とライバルは色相だけでなく明るさでも見分けられる（青緑と赤）。区画の縁には、色に加えて旗の形も付ける

## 文字

- **本文**：Zen Maru Gothic（Google Fonts）。`title` 22px、`heading` 16px、`body` 14px、`caption` 12px
- **数字とラベル**：DotGothic16（Google Fonts）。`figure-lg` 28px、`figure` 15px、`label` 13px
- スマホでも本文は14px、補足は12pxを下限にする。縮めて収めず、折りたたむ

読み込み：`https://fonts.googleapis.com/css2?family=DotGothic16&family=Zen+Maru+Gothic:wght@500;700&display=swap`

## ドット絵と素材

- MCHの素材（ヒーロー、エクステンション、ランドセクタ、キャラクター）は64×64を原寸として、拡大は整数倍だけ。画像には必ず `image-rendering: pixelated`
- 地図の1マス（`tile`）は64px。地図とUIで1ドットの大きさをそろえる
- 区画の設備はエクステンションの絵を原寸で置く。段階（Lv1〜5）はレアリティ（Common〜Legendary）。住宅はドールハウス
- 道路、地形、駅、物流センターのように、エクステンションにない施設だけをスクリプトで生成する。描画ルールは `docs/pixel-rules.md` に従う
- 色数の少ないシリーズ（ラーメン、お寿司、いちごケーキなど）を優先する

## 形と余白

- 余白は4pxの格子（`space-1`〜`space-6`）。画面の左右の余白は常に `space-4`（16px）
- 枠線は `border-panel`（3px）の `night-800`。スプライトのほぼ黒の外郭線と太さをそろえる
- 角丸は `radius-sm`（紙の行）、`radius-md`（パネル）、`radius-lg`（吹き出し、スマホのシート）、`radius-pill`（チップ）
- 影は使わない。重なりは枠線と面の明暗で見せる

## アイコン

- 絵文字は使わない
- 物はMCHのスプライトで示す（店はエクステンション、人はヒーロー、助言はマインちゃん）
- 操作の記号だけ、2pxの線で描いたSVGアイコンを使う（閉じる、開く、戻る、稟議の書類）

## 画面幅ごとの組み方

| 幅 | 組み方 |
| --- | --- |
| 1024px以上（`bp-desktop`） | 3列の机：左にお品書き、中央に地図、右に掲示板とかわら版。下に指示ボタンの列と「月を進める」 |
| 600〜1023px（`bp-tablet`） | 2列：左に地図、右にお品書き・掲示板・かわら版を縦に積み、それぞれ折りたためる |
| 599px以下（スマホ） | 地図が上、折りたたみの行が下、一番下にドック。詳しい情報は下から出るシートで開く |

### スマホの規則（縦長の狭い画面）

1. **常に見えるのは4つだけ**：ヘッダー（屋号、資金、日付）、地図、折りたたみの行、ドック（指示・月を進める）
2. **ヘッダーは1行**。店の数や知名度は、ヘッダーを押すと下に開くチップの列に入れる
3. **地図は画面の上半分以上**。原寸（1x）で表示し、指でずらして見る。ピンチで2倍・3倍に切り替える（中間の倍率は使わない）
4. **かわら版は地図の下端に1行**で流す。押すと記事が開く
5. **お品書き・声・稟議は折りたたみの行**（`row-fold`、52px）にする。閉じた状態でも、一番大事な数字1つ（利益、期限が近い件数、未決の件数）を行の右に出す
6. **詳しい情報は下から出るシート**（`BottomSheet`）。高さは3段階：閉じる、半分（地図が上に見える）、全体。シートの上端をつまんで動かせる
7. **区画を押すとシートが半分まで開く**。地図はシートに隠れない位置まで自動でずれる
8. **ドックは2つのボタンだけ**：左に「指示」（出店・物流・人・投資をシートで開く）、右に「月を進める」
9. **タップの的は44px以上**（`touch-min`）。文字を小さくして収めない

## 部品

| 部品 | 中身 |
| --- | --- |
| `Ledger` | 先月の決算（お品書き）。売上、費用の行、利益 |
| `EmaCard` | ステークホルダーの要望（絵馬）。支持度、要望、期限 |
| `Kawaraban` | ライバルや事件のニュース（かわら版） |
| `LotTile` | 地図の区画。エクステンションの絵と、持ち主の縁 |
| `StatChip` | ヘッダーの数字 |
| `CommandButton` | 指示ボタン。上帯の色で種類を示す |
| `MonthButton` | 「月を進める」 |
| `AdvisorBubble` | マインちゃんの助言 |
| `BottomSheet` | スマホのシート（3段階） |
| `FoldRow` | スマホの折りたたみの行 |
